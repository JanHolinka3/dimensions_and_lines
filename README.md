# Dimensions and Lines — Legacy Repository

Dimensions and Lines is a Blender addon for creating **CAD-style dimensions, technical drawings, and blueprint-style layouts** directly in the 3D viewport.

## Project status

⚠️ **This repository is a legacy / free version provided for reference and archival purposes.**  
Active development, updates, and author support continue independently as a commercial tool.

## Features (legacy version)

- **CAD-style dimensioning** created interactively with the mouse  
- **Non-destructive mesh lines** generated from edges (renderable like any other geometry)  
- **Dedicated snapping system** for accurate placement (including snapping to line centers)  
- **Camera setup for paper sizes** with render resolution based on selected DPI  
- Multiple **line types** and **hatch types**
